# AGENTS

Este projeto utiliza:

- Next.js App Router
- TypeScript Strict
- Tailwind v4
- Shadcn
- Auth.js
- Firebase

Sempre seguir:

- Server Components por padrão
- Mobile First
- Não utilizar any
- Toda validação via Zod
- Nunca acessar Firestore diretamente nas páginas
- Toda regra de negócio deve ficar em modules/

Leia docs/ antes de implementar qualquer feature.
