# Imagens das missões do seed

Geradas com a ferramenta integrada `image_gen`, usando as imagens existentes como referências de estilo. Os PNGs finais foram preparados em 256×256, com fundo opaco, em `public/images/assets/missions/`. As imagens anteriores foram preservadas.

## Prompt base

```text
Use case: stylized-concept. Asset type: square game mission illustration for a mobile Pokedex event app. Generate one standalone image, square composition, styled as deliberate crisp low-resolution pixel art, intended to be displayed at 256x256. Match the visual style of the reference assets: retro RPG pixel art with sharp stepped outlines and visible square pixels, fantasy combined with technology, deep nearly-black midnight navy background, luminous purple and cyan highlights with limited lime accents, small magical sparks, centered subject occupying most of the frame, ground or stone platform near bottom, generous small dark edge margins. Opaque background, no transparency. No typography, no numbers, no logos, no watermarks, no photo realism, no smooth 3D or vector rendering. The provided local images are STYLE REFERENCES ONLY, not edit targets; create an entirely new mission illustration.
```
