## Prompts usados

### Caldeirão do Código

> Use case: stylized-concept. Generate one new square game mission illustration for 'Caldeirão do Código', a mission at fictional Code Cauldron. Reference image is style reference only, not edit target. Match its crisp low resolution pixel art, near-black navy background, purple halo, cyan and lime accents, centered hooded fantasy technology character, rich pixel shading and readable silhouette. Subject: hooded alchemist stirring a cauldron of glowing lime code-shaped sparks with a cyan circuit wand; small circuit tiles around cauldron. No text, letters, logos, border or watermark. Single illustration, full square, suitable for downscaling to 256x256. Save generated asset.

### Guardião dos Dados

> Use case: stylized-concept. Generate one new square game mission illustration for 'Guardião dos Dados', at fictional Data Crypt. Input is style reference only. Match crisp low resolution pixel art, near-black navy background, purple halo, cyan and lime highlights, rich pixel shading, centered fantasy technology figure and silhouette. Subject: armored hooded guardian protecting a cyan glowing database crystal vault with a small circuit shield, in a dark crypt. Same visual family as reference; new subject. No text, letters, logos, border, watermark. Single square illustration suitable for downscaling to 256x256.
